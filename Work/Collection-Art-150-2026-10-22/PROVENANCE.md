# Generation provenance

Post-MOTOR categories use the same reviewed COL-MOTOR-006 rendering-style reference, with explicit instructions to depict each catalog subject and never inherit its motorcycle identity. Subject design directions and exact catalog art_brief are included per prompt. Each is a separate native imagegen call. Later framing/design corrections reference that item's own existing final; the recorder first validates its prior hash and task ownership, preserves those bytes under variants, then selects the newly returned native source. Exact request JSON accompanies later calls.

All assets are generated by built-in image_gen with transparent_background=true. No CLI/API key, paid external service, stock image, code-drawn final, raster cleanup, or final resampling is used. The generated source path and SHA256 of the byte-identical selected copy are recorded in MANIFEST.csv. Prompt files contain the actual text supplied to the tool.

Initial COL-CAR-00, COL-MOTOR-004 and COL-MOTOR-006: no input reference. COL-CAR-00 v2: edit of variants/COL-CAR-00-v1.png. Initial COL-MOTOR-010 and COL-MOTOR-012: style reference to original COL-MOTOR-006, generated exec-b6999ddd-3f9c-461b-b8d7-652f0598bdab.png (preserved under variants/COL-MOTOR-006-84e6a386f7f7.png). The four reframe calls use the respective original asset, preserved in variants by prior SHA prefix. Remaining MOTOR production uses the reframed images/COL-MOTOR-006.png as style and scale reference, not as a substitute for the requested object's identity.

Preview JPGs and HTML are review-only derivatives. Final PNGs remain exactly the tool's generated bytes, including native 1254x1254 dimensions and original alpha/C2PA metadata. Colored RGB artifacts visible in some tool previews were checked on alpha-composited light/navy views; native detail crops of COL-MOTOR-004 and COL-MOTOR-012 show those colors disappear with correct alpha application. Faint near-transparent pixels outside the main silhouette remain in the native output. Crop checks therefore record both raw alpha bounds and visible alpha bounds above 16/255; this threshold does not modify image pixels.
