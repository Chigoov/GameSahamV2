## 3. Rincian 12 Fitur Strategis dalam Bahasa Manusia

### 1. Deposito Bank Berjangka & Penalti Penarikan Dini (*Time Deposits*)
* **Bahasa Manusia:**
  Tempat menyimpan uang kas menganggur untuk mendapatkan bunga pasif yang pasti:
  - *Tenor 10 Sesi:* Bunga harian + bonus 10%.
  - *Tenor 25 Sesi:* Bunga harian + bonus 25%.
  - *Tenor 50 Sesi:* Bunga harian + bonus 50%.
* **Dilema Finansial:**
  Jika di tengah jalan pemain mencairkan deposito sebelum jatuh tempo karena butuh uang tunai cepat untuk membeli saham murah, **seluruh bunga yang sudah terkumpul otomatis hangus (*Lost Interest Penalty*)**.

### 2. Asuransi Portofolio Lindung Nilai (*Portfolio Insurance / Hedging*)
* **Bahasa Manusia:**
  Sebelum hari bursa dibuka saat volatilitas tinggi, pemain bisa membayar premi polis asuransi portofolio.
* **Perlindungan Modal:**
  Jika pasar mendadak ambruk parah (*crash* > 5%), perusahaan asuransi otomatis mengganti 80% dari kerugian nilai saham pemain.

### 3. Penyelamatan Kebangkrutan & Restrukturisasi (*Insolvency Bailout*)
* **Bahasa Manusia:**
  Ketika pemain bangkrut total (utang bank melebihi aset dan kas habis), game tidak langsung berakhir kaku. Pemain masuk ke fase *Chapter 11 / Restrukturisasi*:
  - Pemain bisa melelang aset koleksi mewah secara darurat.
  - Mengajukan negosiasi penjadwalan utang dengan konsultan penyehat keuangan (*Turnaround Specialist*).

### 4. Perusahaan Induk Konglomerasi (*Holding Company & Subsidiaries*)
* **Bahasa Manusia:**
  Pemain mendirikan entitas grup konglomerasi (*holding*) yang membawahi anak-anak usaha di berbagai sektor (Keuangan, Energi/Tambang, Konsumer, Teknologi).
* **Fasilitas Arus Kas:**
  Holding company dapat menyuntikkan modal (*capital injection*) atau menarik dividen antar anak usaha secara internal tanpa potongan pajak bursa.

### 5. Guncangan Pasar Mendadak (*Market Shock & Black Swan Events*)
* **Bahasa Manusia:**
  Peristiwa bencana ekonomi global mendadak yang meruntuhkan indeks bursa 10–20% dalam 1 sesi perdagangan. Hanya pemain yang memegang cadangan kas tunai atau aset emas/safe-haven yang bisa selamat dan memborong saham di harga dasar (*bottom fishing*).

### 6. Krisis Rantai Pasok & Lonjakan Biaya Sektor (*Supply Chain Crisis*)
* **Bahasa Manusia:**
  Krisis kelangkaan bahan baku atau jalur logistik laut yang menaikkan biaya produksi emiten manufaktur dan retail secara drastis. Saham-saham terkait mengalami penurunan margin keuntungan, sementara sektor komoditas energi justru melesat naik.

### 7. Pohon Riset Bisnis & Teknologi Finansial (*Income Research Tech Tree*)
* **Bahasa Manusia:**
  Pohon teknologi R&D yang bisa ditingkatkan oleh pemain menggunakan uang kas firma:
  - *Jalur Algoritma:* Membuka deteksi sinyal arah pasar otomatis.
  - *Jalur Efisiensi:* Memangkas biaya operasional kantor dan komisi transaksi bursa.
  - *Jalur Sindikasi:* Memperbesar batas maksimal dana investor luar yang sanggup dikelola.

### 8. Jalur Bonus Disiplin Harian (*Streak Day Strip & Broken Streak Alarm*)
* **Bahasa Manusia:**
  Sistem apresiasi kedisiplinan trader:
  - Login dan trading berturut-turut dari Hari 1 hingga Hari 7+ melipatgandakan bonus kas harian.
  - Jika pemain absen 1 hari, sistem menyalakan peringatan *Broken Streak* dan hadiah kembali ke titik awal.

### 9. Hak Suara & Dominasi Sektor Bursa (*Sector Dominance & Influence*)
* **Bahasa Manusia:**
  Jika pemain berhasil mengakumulasi lebih dari 25% total kapitalisasi pasar di satu sektor industri (misal perbankan), pemain dinobatkan sebagai **Penguasa Sektor**:
  - Mendapatkan hak veto penentu arah sektor.
  - Menikmati pemotongan biaya broker permanen untuk seluruh transaksi saham di sektor tersebut.

### 10. Perang Bakat & Pembajakan Karyawan Elit (*Headhunting & Talent Poaching*)
* **Bahasa Manusia:**
  Persaingan SDM antar firma investasi:
  - Firma pesaing bisa membajak (*poach*) analis riset bintang milik pemain jika gaji atau moralnya rendah.
  - Pemain bisa menyewa jasa *Headhunter* untuk membajak manajer investasi legendaris dari firma kompetitor guna mendongkrak reputasi dan return dana kelolaan (AUM).

### 11. Meracik Reksa Dana Kustom (*Custom Mutual Funds & Asset Allocation*)
* **Bahasa Manusia:**
  Pemain bisa merancang produk reksa dana campuran sendiri menggunakan antarmuka diagram lingkaran (*Pie Chart*):
  - Mengatur komposisi: misal 50% Saham Blue Chip, 20% Saham Tambang, 20% Pasar Uang, dan 10% Kas.
  - Menjual unit reksa dana ini ke klien investor untuk mendapatkan aliran komisi manajemen (*management fee*) berkala.

### 12. Perdagangan Aset Kripto Alternatif (*Crypto Asset Trading*)
* **Bahasa Manusia:**
  Bursa aset digital 24 jam dengan volatilitas liar tanpa batasan suspensi (*Auto Rejection*). Menjadi instrumen pelengkap bagi pemain agresif yang ingin mengejar cuan kilat berisiko tinggi di luar jam bursa saham reguler.

## 4. Skema Database SQLite Lokal Tambahan (Fase 3)

Untuk mendukung 12 fitur strategis ini secara *offline-first*, disiapkan **8 tabel database baru**:

```sql
-- 1. Deposito Bank Berjangka
CREATE TABLE TimeDeposits (
    DepositId TEXT PRIMARY KEY,
    PrincipalAmount DECIMAL(18, 4) NOT NULL,
    TenorSessions INTEGER NOT NULL, -- 10, 25, 50
    DailyInterestRate DECIMAL(6, 4) NOT NULL,
    BonusMultiplier DECIMAL(4, 2) NOT NULL,
    StartSession INTEGER NOT NULL,
    MaturitySession INTEGER NOT NULL,
    IsWithdrawnEarly INTEGER NOT NULL DEFAULT 0,
    IsMatured INTEGER NOT NULL DEFAULT 0,
    AccruedInterest DECIMAL(18, 4) NOT NULL DEFAULT 0
);

-- 2. Polis Asuransi Portofolio
CREATE TABLE PortfolioInsurancePolicy (
    PolicyId TEXT PRIMARY KEY,
    PurchasedSession INTEGER NOT NULL,
    ExpirySession INTEGER NOT NULL,
    CoveragePercentage DECIMAL(5, 2) NOT NULL DEFAULT 80.0,
    PremiumPaid DECIMAL(18, 4) NOT NULL,
    IsClaimed INTEGER NOT NULL DEFAULT 0
);

-- 3. Produk Reksa Dana Kustom Pemain
CREATE TABLE CustomMutualFunds (
    FundId TEXT PRIMARY KEY,
    FundName TEXT NOT NULL,
    EquityWeightPct DECIMAL(5, 2) NOT NULL,
    CommodityWeightPct DECIMAL(5, 2) NOT NULL,
    CryptoWeightPct DECIMAL(5, 2) NOT NULL,
    CashWeightPct DECIMAL(5, 2) NOT NULL,
    TotalAUM DECIMAL(18, 4) NOT NULL DEFAULT 0,
    ManagementFeePct DECIMAL(5, 2) NOT NULL DEFAULT 1.5,
    PerformanceFeePct DECIMAL(5, 2) NOT NULL DEFAULT 15.0
);

-- 4. Anak Perusahaan Induk (Holding Subsidiaries)
CREATE TABLE HoldingSubsidiaries (
    SubsidiaryId TEXT PRIMARY KEY,
    SectorName TEXT NOT NULL,
    CompanyName TEXT NOT NULL,
    CapitalInjected DECIMAL(18, 4) NOT NULL DEFAULT 0,
    CurrentCash DECIMAL(18, 4) NOT NULL DEFAULT 0,
    CompanyValuation DECIMAL(18, 4) NOT NULL DEFAULT 0,
    RetainedEarnings DECIMAL(18, 4) NOT NULL DEFAULT 0
);

-- 5. Pasar Bakat Analis & Headhunting
CREATE TABLE StaffHeadhuntingMarket (
    CandidateId TEXT PRIMARY KEY,
    CandidateName TEXT NOT NULL,
    RoleTitle TEXT NOT NULL,
    SkillRating INTEGER NOT NULL,
    PoachCost DECIMAL(18, 4) NOT NULL,
    ExpectedSalary DECIMAL(18, 4) NOT NULL,
    CurrentFirmEmployer TEXT NOT NULL,
    LoyaltyScore DECIMAL(5, 2) NOT NULL DEFAULT 100.0,
    IsHiredByPlayer INTEGER NOT NULL DEFAULT 0
);

-- 6. Pohon Riset Teknologi Finansial (Tech Tree)
CREATE TABLE ResearchTechTreeProgress (
    NodeId TEXT PRIMARY KEY,
    NodeName TEXT NOT NULL,
    Category TEXT NOT NULL, -- ALGO, EFFICIENCY, SCALE
    TierLevel INTEGER NOT NULL,
    UpgradeCostCash DECIMAL(18, 4) NOT NULL,
    IsUnlocked INTEGER NOT NULL DEFAULT 0,
    StatBonusType TEXT NOT NULL,
    StatBonusValue DECIMAL(6, 2) NOT NULL
);

-- 7. Pelacak Jalur Disiplin Harian (Streak)
CREATE TABLE DailyStreakTracker (
    PlayerId TEXT PRIMARY KEY,
    CurrentStreak INTEGER NOT NULL DEFAULT 0,
    LongestStreak INTEGER NOT NULL DEFAULT 0,
    LastLoginSession INTEGER NOT NULL DEFAULT 0,
    IsStreakBroken INTEGER NOT NULL DEFAULT 0,
    RewardMultiplier DECIMAL(4, 2) NOT NULL DEFAULT 1.0
);

-- 8. Status Dominasi & Pengaruh Sektor Bursa
CREATE TABLE SectorDominanceStatus (
    SectorName TEXT PRIMARY KEY,
    PlayerOwnershipPct DECIMAL(5, 2) NOT NULL DEFAULT 0.0,
    IsDominantPlayer INTEGER NOT NULL DEFAULT 0,
    VetoPowerActive INTEGER NOT NULL DEFAULT 0,
    FeeDiscountPct DECIMAL(5, 2) NOT NULL DEFAULT 0.0
);
```
