# Bukti dan APK

Belum ada bukti pengujian atau APK. Hermes menyimpan log/screenshot/report pada subfolder ID tugas dan APK final beserta checksum pada release/.

Binary, data pemain dan keluaran build tidak di-track secara default. Laporan teks yang diperlukan reviewer dapat ditambahkan secara selektif setelah ditinjau; jangan force-add secrets atau dataset tanpa hak penggunaan.
